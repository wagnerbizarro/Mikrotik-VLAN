# **Configured various types of VLANs on MikroTik**  

### **About**  

Hello everyone! In this lab, I configured various types of VLANs on MikroTik equipment:    
Tagged VLANs, Untagged VLANs, and Bridge VLANs.  
 Using Wireshark, it is possible to see the 802.1Q (Dot1Q) tag in the Ethernet header.
